# DaoQuetta

DaoQuetta is a real-time processing engine that leverages an event-driven architecture for high-performance data aggregation.

DaoQuetta is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoQuetta.git`
2. `cd DaoQuetta`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaoQuetta, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
